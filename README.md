# AI Interview Trainer Agent

## Overview
AI Interview Trainer Agent is an AI-powered web application designed to help students prepare for technical and HR interviews. The system generates interview questions, evaluates answers, provides feedback, and improves placement preparation using AI.

---

## Features
- AI-generated interview questions
- Technical and HR interview preparation
- Intelligent answer evaluation
- Real-time feedback and scoring
- Personalized recommendations
- User-friendly interface

---

## Technologies Used
- Python Flask
- HTML, CSS, JavaScript
- IBM watsonx.ai
- IBM Granite Models
- LangFlow
- SQLite Database
- RAG (Retrieval-Augmented Generation)
- FAISS / Chroma Vector Database
